# Описание программы
С одномерным массивом, состоящим из n вводимых с клавиатуры
положительных и отрицательных целых чисел выполнить следующие
вычисления: Номер последнего отрицательного элемента, делящегося на 3 без
остатка

# Алгоритм и блок-схема
Программа начинается с подключения двух библиотек: stdio.h нужна для функций ввода-вывода printf и scanf, а locale.h — для функции setlocale, которая включает поддержку русского языка в консоли, чтобы кириллица в сообщениях отображалась корректно. Затем с помощью директивы #define N 10 задаётся константа — размер массива, равный 10; использование макроса удобно тем, что при необходимости изменить размер массива достаточно поменять число в одном месте. В функции main сначала вызывается setlocale(LC_ALL, "Russian"), после чего объявляются две переменные: целочисленный массив A из N элементов, в который будут записаны введённые числа, и переменная lastIndex, инициализированная значением -1. Эта переменная играет роль «маркера»: значение -1 означает, что подходящий элемент ещё не найден, поскольку допустимые индексы массива начинаются с нуля, и -1 заведомо не может быть настоящим индексом. Далее программа выводит приглашение «Введите 10 целых чисел» и запускает цикл for с параметром i от 0 до N-1, внутри которого на каждой итерации печатается подсказка вида a[i+1] = (нумерация для пользователя ведётся с единицы, хотя внутри массива индексы начинаются с нуля) и с помощью scanf("%d", &A[i]) в текущую ячейку массива считывается целое число; оператор & здесь обязателен, потому что scanf нужно передать адрес памяти, куда записать значение. После заполнения массива начинается второй цикл — ключевой в программе: он организован как обратный проход, то есть параметр i меняется от N-1 (последний индекс) вниз до 0. Такой порядок выбран специально: если двигаться по массиву с конца к началу, то первый же элемент, удовлетворяющий условию, и будет последним по индексу среди всех подходящих, поэтому не нужно просматривать весь массив и запоминать несколько кандидатов. Внутри цикла стоит условный оператор if (A[i] < 0 && A[i] % 3 == 0), который проверяет два требования одновременно: элемент должен быть отрицательным (A[i] < 0) и должен делиться на 3 без остатка (A[i] % 3 == 0, где % — операция взятия остатка от деления). Оба условия соединены логическим «И» (&&), то есть должны выполняться вместе. Стоит отметить, что в языке C операция % для отрицательных чисел даёт остаток того же знака, что и делимое, поэтому для чисел, кратных трём (например, -9, -12, -15), остаток действительно равен нулю, и условие работает корректно. Если элемент удовлетворяет обоим требованиям, в переменную lastIndex записывается его индекс i, а затем выполняется оператор break, который немедленно прерывает цикл — дальше искать нет смысла, поскольку мы уже нашли самый последний (по индексу) подходящий элемент. Если же цикл завершился, а подходящих элементов не встретилось, lastIndex так и останется равным -1. После цикла стоит проверка if (lastIndex != -1): если условие истинно, значит, элемент найден, и программа выводит его номер (индекс) и само значение A[lastIndex]; в противном случае выводится сообщение о том, что в массиве нет отрицательных элементов, делящихся на 3. Завершается программа оператором return 0, который сигнализирует об успешном выполнении. Таким образом, вся логика сводится к трём шагам: ввод массива, обратный поиск первого подходящего элемента с конца с проверкой двух условий, и вывод результата в зависимости от того, был ли элемент найден.

# Реализация программы
#include <stdio.h>      /* для printf, scanf */
#include <locale.h>     /* для setlocale (русский язык) */

#define N 10            /* размер массива — константа 10 */

int main() {
    /* Включаем поддержку русского языка в консоли */
    setlocale(LC_ALL, "Russian");

    /* Объявление массива и переменной для индекса */
    int A[N];               /* массив из 10 целых чисел */
    int lastIndex = -1;     /* индекс последнего подходящего элемента (-1 = не найден) */

    /* ---------- Блок 1: Ввод массива ---------- */
    printf("Введите %d целых чисел:\n", N);
    for (int i = 0; i < N; i++) {
        printf("a[%d] = ", i + 1);   /* нумерация для пользователя с 1 */
        scanf("%d", &A[i]);          /* читаем число в A[i] */
    }

    /* ---------- Блок 2: Поиск последнего отрицательного, кратного 3 ---------- */
    for (int i = N - 1; i >= 0; i--) {       /* обратный проход: с конца к началу */
        if (A[i] < 0 && A[i] % 3 == 0) {     /* элемент отрицательный И делится на 3 */
            lastIndex = i;                   /* запоминаем индекс */
            break;                           /* нашли последний — выходим */
        }
    }

    /* ---------- Блок 3: Вывод результата ---------- */
    if (lastIndex != -1) {
        printf("\nНомер последнего отрицательного элемента,\n");
        printf("делящегося на 3 без остатка: %d\n", lastIndex);
        printf("(его значение: %d)\n", A[lastIndex]);
    }
    else {
        printf("\nВ массиве нет отрицательных элементов, делящихся на 3.\n");
    }

    return 0;
